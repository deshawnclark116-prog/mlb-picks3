## Exact selection and scoring rules

- Use each game's **last frozen pre-tip V5 model forecast** (not a postgame re-simulation).
- The frontend displays the **model's rounded own numerical projection**, using the custom x.6-up rule, plus the chance of reaching **at least that number**. A 1.4 steal mean is displayed as **1+ steals**; 2.0 actual steals reaches that threshold, but is not an exact-mean forecast.
- System Picks exclude `turnovers`, known reported OUT players, active probability below 75%, and nonmeaningful whole-number thresholds. The grader's old cached `frontend_rank` on turnover rows is intentionally ignored and the first four remaining ranked eligible rows are the featured tiles.
- Every qualified row counts in the expanded panel. DNP counts as a **miss**, not as a silently removed event. Mean absolute numeric error excludes DNP because the forecast is conditional on playing; probability hit scoring includes DNP.
- Model `probability_including_dnp` was used where present. These percentages have **not** been verified as forward calibrated and no sportsbook line was used.
